# Game-making tool areas

This is a checklist of capability areas taken from a public survey of an AI game-making product's tool directory. It describes scope only. Write all agent names, personas, and descriptions from scratch. That product's engine is source-available rather than open source, and we found no permission to reuse its characters or artwork.

## Design
- **Brief:** collect all decisions about the game in one place.
- **Game design:** produce a design a builder can follow.
- **Controls:** keyboard, touch, and gamepad schemes.
- **World:** develop a game world from one sentence.
- **Characters:** a cast with portraits and voices.
- **Mood board:** show the visual direction before assets get made.

## Art
- **Images:** title screens, menus, backgrounds, portraits.
- **Sprites:** short description to sprite sheet.
- **Anime:** characters, faces, backgrounds.
- **Poses:** put a character in a chosen pose.
- **Vector art:** glowing line art ready for a game.
- **Textures:** seamless textures for floors, walls, and 3D.
- **Layers:** split a picture into layers a game can use.

## 3D
- **3D models:** a model from a sentence or a picture.

## Screens and effects
- **Logo:** blend selected styles into a logo.
- **Title screen:** an animated title screen.
- **Game UI:** menus and HUD that match the game.
- **Shaders:** animated backgrounds and effects.
- **Videos:** a script into intros and cutscenes.

## Sound
- **Music:** tracks for the game's screens.
- **Sound effects:** effects for the game.
- **Synth:** retro game sounds the user can shape.

## Working patterns worth having
- A chief-of-staff role that coordinates specialists, so the user can hand over a task and have the parts delegated.
- Users can operate a tool themselves or ask the matching specialist, and output goes into the game.
- Specialists have adjustable personality settings.
- Build with your own coding agent: design first, then a local agent builds and playtests with a CLI and an installed skill.

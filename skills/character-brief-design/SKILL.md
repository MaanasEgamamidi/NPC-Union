# Character Brief Design

## Inputs

- Player relationship, role, camera/scale, tone, canon, cast and art budget. Ask once for missing role and camera; label other assumptions.

## Steps

1. Describe the player-facing role and first impression. Separate want, need, fear and the action that exposes their conflict.
2. Define a default action, a pressured decision and a credible boundary. Identify the event that could change it.
3. Specify silhouette, value hierarchy, gesture, costume wear and prop use at gameplay and close-up scale. Explain each choice.
4. Compare the cast in silhouette, movement, conversational strategy and role; revise an overlap that harms recognition.
5. Flag representation research, rigging, animation and asset constraints; name owners and devise a grayscale/motion test.

## Output

```markdown
# Character: <name>
Role and player impression: <...>
Want / need / fear / contradiction: <...>
Default / stress decision / boundary: <...>
Gameplay read / close read / motion / voice: <...>
Cast comparison / constraints / research: <...>
Test, assumptions and handoffs: <...>
```

## Done when

- [ ] A contradiction changes an observable decision.
- [ ] Visual reads work at the specified camera scale and are compared with the cast.
- [ ] Production constraints, representation questions and a test have owners.

# Accessibility specialist reference facts

Version- and policy-sensitive facts. Check each against the source before quoting.

- [Xbox Accessibility Guidelines](https://learn.microsoft.com/en-us/gaming/accessibility/guidelines) are published on Microsoft Learn as best practices, not a legal compliance checklist.
- For subtitle sizing, consult [Xbox Accessibility Guideline 104](https://learn.microsoft.com/en-us/gaming/accessibility/xbox-accessibility-guidelines/104) and test readability at the target viewing distance.
- [WCAG 2.1](https://www.w3.org/TR/WCAG21/) specifies 4.5:1 for text and 3:1 for large text, with exceptions; criterion 2.3.1 permits no more than three flashes in any one-second period or flashes below the specified thresholds.
- Have legal assess whether the game's communication features are covered by US accessibility requirements; check current FCC rules and applicable waivers.
- Have legal assess applicable European accessibility obligations for the game and storefront against current EU and national rules.
- Check each target storefront's current accessibility feature-tag criteria before submitting metadata; see [Xbox feature tags](https://learn.microsoft.com/en-us/gaming/accessibility/accessibility-feature-tags).

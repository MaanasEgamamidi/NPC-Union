# Live ops designer reference notes

Version and policy sensitive facts. Check each against the live source before quoting it.

- Genshin Impact runs versions on a cycle of roughly six weeks. UNVERIFIED for current cadence.
- [Halo Infinite battle passes](https://support.halowaypoint.com/hc/en-us/articles/4408373413268-Halo-Infinite-Battle-Pass-Free-to-Play-FAQ) remain available; progressing a pass after its Operation ends requires the Premium Battle Pass.
- [Apple App Review Guidelines 3.1.1](https://developer.apple.com/app-store/review/guidelines/) require apps offering purchased randomized virtual items to disclose the odds of each item type before purchase.
- [Google Play policy](https://support.google.com/googleplay/android-developer/answer/18265346) requires disclosure of odds for randomized virtual items before and close to the purchase.
- Valve publishes announced seasonal sale dates in [Steamworks](https://partner.steamgames.com/doc/marketing/upcoming_events); check the current listing rather than recalling dates.
- Some regions regulate paid random rewards (for example Belgium's stance on loot boxes). UNVERIFIED; route to game-legal-advisor.

# Community manager platform facts

Facts here change over time. Check each one against the source before relying on it.

- Steam flags "off-topic review activity" periods and excludes them from the review score by default; players can opt in to include them. Introduced March 2019. UNVERIFIED for current behavior.
- Steam announcements are made through the Events and Announcements tool in Steamworks, with event types such as small update, regular update and major update. Required image sizes: UNVERIFIED, check Steamworks docs.
- Discord member timeouts can last up to 28 days. UNVERIFIED for current limit.
- Discord Announcement Channels can be followed by other servers; there is a publish rate limit per channel. Exact limit UNVERIFIED.
- Discord AutoMod supports keyword filters, spam filters and mention-spam limits in Community servers. Feature set UNVERIFIED, check the Discord Help Center.

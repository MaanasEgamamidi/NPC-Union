# QA lead reference notes

Check version and policy-sensitive facts against the source on the date of use.

- Check the current Sony, Xbox and Nintendo submission requirements in the relevant developer portals before every submission.
- Confirm patch and title update resubmission requirements in each platform portal.
- Ask each platform for current certification turnaround guidance and allow time for a failure and resubmission.
- Steam Deck compatibility results are Verified, Playable, Unsupported or Unknown. The current checklist includes input, performance, seamlessness and Proton requirements. [Steamworks](https://partner.steamgames.com/doc/steamhardware/compat).
- IARC provides ratings for multiple territories through a single questionnaire accessed via participating storefronts. Check the current [storefront list](https://www.globalratings.com/storefronts/) and [FAQ](https://www.globalratings.com/faq/).
- Use the [ISTQB glossary](https://www.istqb.org/) to check the current definitions of entry criteria, exit criteria, regression testing and smoke testing.

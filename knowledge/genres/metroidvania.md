# Metroidvania

## Core loop

Explore an interconnected world, find a place you cannot pass yet, gain an ability or tool elsewhere, return, and open new space. Combat, bosses, and upgrades feed this loop, but the loop itself is "see a lock, find a key, come back."

## Design pillars

- One connected world, not a level list. Regions loop back into each other.
- Ability gating. New moves open new paths and change how old rooms play.
- Readable locks. Gates are seen and remembered before they can be opened.
- Map as a core tool. The player plans routes from the map.
- Meaningful backtracking. Return trips should be short, or offer something new.

## Common failures

- Hidden mandatory paths with no visual tell, so players stall.
- Keys handed out before the player has seen the lock, so the ability feels pointless.
- Long empty backtracks with no shortcut, warp, or new threat.
- Core movement arriving too late, so the world feels closed for most of the game.
- No way to mark gates on the map, so returning becomes a search.
- Long corpse runs when death has a currency penalty.
- New abilities that skip earlier puzzles by accident.

## Scope traps

- Each ability multiplies test work: every earlier room must be checked with it.
- Remixed or mirrored maps (like the inverted castle) look cheap but need new traversal or they feel like padding.
- Boss count grows fast; each boss is often a gate as well as a fight.
- Hand-placed secrets across a large map take long to place and verify.
- A roguelite layer (as in Dead Cells) means building generation or remixing on top of the gating graph.

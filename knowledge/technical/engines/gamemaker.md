# GameMaker snapshot

- The publisher recommends LTS 2026.0.0, current IDE 16 / GMS2 runtime 23, [release notes](https://releases.gamemaker.io/release-notes/2026/0). The newer beta 2026.100.0 release 12 is IDE 1199 / GMS2 runtime 1133, [beta notes](https://releases.gamemaker.io/release-notes/2026/100). GMRT is separately developed and beta; do not confuse it with the GMS2 runtime. [Release overview](https://releases.gamemaker.io/). Checked 2026-11-05.
- GameMaker is proprietary. Publisher [licence upgrade guidance](https://test.gamemaker.io/en/help/articles/how-to-upgrade-your-gamemaker-licence) says non-commercial use is free, Professional is $99.99 one-time for commercial distribution on listed non-console platforms, and Enterprise is $79.99 monthly or $799.99 yearly for console exports. Platform-holder approval and requirements remain separate. Check current terms, currency and eligibility before purchase. Checked 2026-11-05.
- Use the [GameMaker manual](https://manual.gamemaker.io/) and its version selector to check event order, APIs, targets and runtime restrictions for the installed project; confirm target SDK requirements for the chosen release.

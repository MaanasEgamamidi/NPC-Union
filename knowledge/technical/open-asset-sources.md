# Open asset sources

Facts about free and open art and 3D asset sites. Each entry says whether it was checked on 2026-11-05.

## Kenney

- Assets: https://kenney.nl/assets
- Licence: CC0 (public domain). Source: https://kenney.nl/support. Verified 2026-11-05.
- Commercial use allowed. Attribution not required; if crediting, use "Kenney".
- Do not use the Kenney logo; it is reserved for the studio's own projects.
- Check each pack's page for its current price and donation options.
- last_verified: 2026-11-05

## Poly Haven

- Site: https://polyhaven.com (HDRIs, textures, 3D models)
- Licence: CC0, described by the site as "effectively Public Domain". Source: https://polyhaven.com/license. Verified 2026-11-05.
- Commercial use allowed. Attribution not required.
- CC0 does not cover logos, user avatars or example renders, which fall under the site's Terms of Service.
- last_verified: 2026-11-05

## ambientCG

- Site: https://ambientcg.com (PBR materials, HDRIs, models)
- Licence: CC0 1.0 Universal. Source: https://docs.ambientcg.com/license/ (https://ambientcg.com/license redirects there). Verified 2026-11-05.
- Commercial use allowed without asking permission. Attribution not required.
- last_verified: 2026-11-05

## OpenGameArt.org

- Site: https://opengameart.org
- Licences are set per entry; many entries are multi-licensed (for example CC-BY and GPL together). Read the licence list on each entry page.
- Entries can contain files by several authors; check the entry text and any credits file.
- Check the current options on [advanced art search](https://opengameart.org/art-search-advanced); the page returned HTTP 403 to an automated fetch on 2026-11-05.
- last_verified: 2026-11-05 (partial)

## Quaternius

- Quaternius Asset License v1.0 permits commercial projects without attribution but restricts standalone redistribution. Check the licence applicable when the asset was obtained; changes are not retroactive. Source: https://quaternius.com/license.html.
- last_verified: 2026-11-05

## Licence quick reference

- CC0: no attribution, commercial use allowed. https://creativecommons.org/publicdomain/zero/1.0/
- CC-BY: commercial use allowed, attribution required (TASL: title, author, source, licence). https://creativecommons.org/licenses/by/4.0/
- CC-BY-SA: commercial use allowed, attribution required, adapted material must be shared under the same licence. https://creativecommons.org/licenses/by-sa/4.0/
- Any NC licence: no commercial use. https://creativecommons.org/licenses/by-nc/4.0/
- GPL on art: unclear how it applies to game assets; route to `asset-license-auditor`.
- Attribution guidance: https://wiki.creativecommons.org/wiki/Best_practices_for_attribution
- Open the applicable licence and read its terms before relying on this summary.
